# Bundled font provenance

These files are bundled so the print build does not depend on system font substitution.

- `DejaVuSans.ttf`: Version 2.37.
- `NanumGothic-Bold.ttf`: Version 3.020;PS 1;hotconv 1.0.57;makeotf.lib2.0.21895.
- `NanumGothic-Regular.ttf`: Version 3.020;PS 1;hotconv 1.0.57;makeotf.lib2.0.21895.
- `NotoSans-Bold.ttf`: Version 2.015; ttfautohint (v1.8.4.7-5d5b).
- `NotoSans-Regular.ttf`: Version 2.015; ttfautohint (v1.8.4.7-5d5b).

Noto Sans regular/bold were copied from the installed LibreOffice runtime; see `OFL-NotoSans.txt` (SIL Open Font License).
Nanum Gothic regular/bold were downloaded from the Google Fonts `ofl/nanumgothic` directory; see `OFL-NanumGothic.txt` (SIL Open Font License).
DejaVu Sans was copied from the system DejaVu distribution; see `LICENSE-DejaVu.txt`.
