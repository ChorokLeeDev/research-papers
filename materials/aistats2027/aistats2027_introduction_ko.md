# 주변 분포 변화의 크기만으로는 컨포멀 예측의 커버리지 감소를 알 수 없는 경우

이초록 | KAIST

배포 데이터가 많이 달라졌다고 해서 특정 모델의 성능이 반드시 크게 나빠지는 것은 아닙니다. 반대로, 변화의 크기가 같아도 모델에 미치는 영향은 다를 수 있습니다. 이 논문은 어떤 요약 정보가 예측집합의 커버리지를 실제로 결정하는지 묻습니다.

## 무엇을 묻는가

커버리지는 예측집합에 실제 정답이 포함될 확률입니다. 반면 분포 변화 검정은 학습 데이터와 배포 데이터의 분포가 다른지를 묻습니다. 논문은 데이터를 회전 방향에 무관한 분포 차이의 크기나 모델 신뢰도의 분포로 요약할 때 어떤 정보가 사라지는지 분석합니다. 변화가 있다는 경고와 커버리지가 얼마나 달라졌다는 결론은 서로 다릅니다.

## 같은 변화 크기, 다른 결과

알려진 이진 로지스틱 정답 생성 법칙 아래에서, 대칭적인 정규분포를 같은 거리만큼 두 방향으로 이동시킵니다. 모델 점수 방향의 이동은 커버리지를 바꿀 수 있지만, 그에 수직인 이동은 점수와 커버리지를 그대로 둡니다. 두 이동의 회전 불변 분포 차이 값은 같습니다. 특정한 크기 조절 구성에서는 원래 오류율이 10%일 때 추가 오류율이 40%포인트에 가까워집니다. 이는 수학적 극한 예시이며, 실제 실패의 빈도나 탐지 불가능한 변화를 뜻하지 않습니다.

## 신뢰도만으로 충분한 조건

조건부 정답 확률이 모델 점수의 로지스틱 함수라는 법칙을 알고 있다면, 절댓값 점수의 분포는 모든 임계값에서의 커버리지를 결정합니다. 이 이진 모형에서는 최대 예측 신뢰도의 분포도 같은 정보를 가집니다. 하지만 원래 데이터에서 신뢰도가 잘 보정되어 있다는 사실만으로는 충분하지 않습니다. 논문은 모든 사례의 신뢰도가 90%이고 점수 분포도 그대로인데, 배포 오류율은 0% 또는 20%가 되는 예를 제시합니다. 원래 오류율은 10%이며, 전체 특성이 주어졌을 때의 정답 법칙은 바뀌지 않습니다.

## 법칙을 모르면 구간으로 말한다

원래 데이터의 신뢰도별 오류율, 배포 신뢰도의 빈도, 특성 분포 밀도비의 상한 Γ가 주어지면 가능한 배포 오류율의 정확한 범위를 구할 수 있습니다. 같은 두 배포 분포가 모든 임계값에서 각각 하한과 상한을 달성합니다. 같은 신뢰도 안에 숨은 조건부 오류율 차이가 없다면, 퇴화된 경우를 제외하고 이러한 모호성이 사라집니다. 유한 표본에서는 원래 데이터의 정답과 배포 점수만 이용해 민감도 구간을 만들고, 미리 정한 후보 중 임계값을 선택할 수 있습니다.

## 근거와 한계

모의실험과 독립적인 최적화 계산으로 공식을 확인했습니다. 두 UCI 데이터셋의 통제된 재표집 실험에서는 72개 조건, 총 7,200회 모두 동시 구간이 참값을 포함했습니다. 그러나 구간은 보수적이고, 72개 중 9개 조건만 위험 정보만 쓴 모집단 범위를 더 좁혔습니다. 실제 배포 환경을 검증한 결과는 아닙니다. 신뢰도 관측만으로 밀도비 상한이나 정답 법칙의 유지 여부를 증명할 수 없으며, 반복해서 계속 확인하는 모니터링까지 보장하지 않습니다.

## 핵심 메시지

분포 변화 경고, 정확한 커버리지 계산, 가능한 커버리지 구간을 구분하고, 각각을 정당화하는 정보와 가정을 함께 제시해야 합니다.
